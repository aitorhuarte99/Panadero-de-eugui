# Panadero de Eugui · web y pedidos online

Web del Panadero de Eugui (Pamplona y Huarte) con pedidos online para recoger en tienda.

## Archivos

| Archivo | Qué es |
|---|---|
| `index.html` | Portada, con las páginas de Productos, Panadería, Cafetería, Repostería, Comida para llevar, Nuestra historia, Contacto/Locales y Bonos regalo |
| `pedidos.html` | Carta completa por categorías, cesta, elección de local, día y hora, y pago |
| `carta.js` | Productos, precios, locales y configuración (lo que hay que tocar para cambiar la carta) |
| `imagenes.js` | Todas las fotos incrustadas |

Los cuatro archivos tienen que estar en la misma carpeta. Abre `index.html` en el navegador.

## Pendiente

- Precios reales de panadería, bollería, repostería, desayunos, bonos y vinos (ahora son orientativos).
- Conectar la pasarela de pago (`CONFIG.urlCrearPago`) y el guardado de pedidos (`CONFIG.urlGuardarPedido`) en `carta.js`.
- A domicilio: solo clientes registrados desde la app del Panadero de Eugui.
